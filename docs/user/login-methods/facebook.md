# Facebook Account

CentralAuth allows you to log in using your Facebook account.

## How it works

- When you start the CentralAuth login flow, click on the `Facebook` button.

<img src="/img/LoginScreen.png" alt="CentralAuth login screen" width="50%" height="50%" />

- You will be redirected to the Facebook login page.

<img src="/img/OAuthFacebook.png" alt="Facebook login screen" width="50%" height="50%" />

- Enter your Facebook credentials to log in.

- If you cancel the authentication flow at Facebook, you can start the process again by clicking on the `Facebook` button.

:::info
When you log in for the first time, Facebook will ask you to authorize CentralAuth to access your Facebook account information. CentralAuth will only access your primary email address for authentication purposes. You only need to authorize CentralAuth once.
:::
