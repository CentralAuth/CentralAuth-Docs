# X Account

CentralAuth allows you to log in using your X account.

## How it works

- When you start the CentralAuth login flow, click on the `X` button.

<img src="/img/LoginScreen.png" alt="CentralAuth login screen" width="50%" height="50%" />

- You will be redirected to the X login page.

<img src="/img/OAuthX.png" alt="X login screen" width="50%" height="50%" />

- Enter your X credentials to log in.

- If you cancel the authentication flow at X, you can start the process again by clicking on the `X` button.

:::info
When you log in for the first time, X will ask you to authorize CentralAuth to access your X account information. CentralAuth will only access your primary email address for authentication purposes. You only need to authorize CentralAuth once.
:::
